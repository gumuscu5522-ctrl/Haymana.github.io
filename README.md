# Haymana Portal

Haymana için modern, responsive Next.js turizm portalı.

## Geliştirme
npm install
npm run dev

## Vercel
Projeyi GitHub'a push ettikten sonra Vercel'de **Add New Project** ile bu repository'yi seçin. Framework: Next.js; ek environment variable gerekmez.

## Not
İletişim bölümünde telefon numarası kullanılmamıştır. Belediye sitesinden alınacak güncel içerikler daha sonra ayrı bölümlere eklenebilir.
